# Hype Man editable sources

- `Hype-Man-Gameplay-v7.aseprite`: 304 character frames, 60 tags, 12 layers, 48 × 48 canvas.
- `Hype-Man-Noise-Pulse.aseprite`: eight-frame expanding wave, 400 ms.
- `Hype-Man-On-a-Roll.aseprite`: eight-frame rear/front buff loop, 640 ms.
- `Hype-Man-Palette.gpl`: the shared palette.

The game uses exported PNG atlases and metadata from `datafiles/hypeman/`. See `docs/hypeman-animation.md` for runtime behavior. The full review package includes GIFs, contact sheets and actual engine screenshots.
